# Block 46 — B226–B230 durable provider lifecycle

This block closes the persistence gap between the accepted commercial records and the existing governed Stripe adapter. It does not store card credentials, expose provider secrets, or silently select live mode.

- B226 binds a verified hosted checkout-session identity to the exact creating attempt.
- B227 claims each verified provider receipt once for exclusive processing and rechecks its stored digest.
- B228 applies checkout completion atomically across the checkout, order, subscription and receipt after exact metadata-lineage verification.
- B229 settles unsupported or failed provider receipts with bounded operational failure codes.
- B230 binds the lifecycle to focused acceptance and the ten-build publication boundary.

Focused verification: `pnpm run test:saas-block46`, library typecheck and API typecheck. B221–B230 require the complete exact-head gate, one push, controlled publication, exact live identity and the full authenticated Chrome smoke.
