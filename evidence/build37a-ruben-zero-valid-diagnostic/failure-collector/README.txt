BIMLog Navisworks 2025 Failure Collector

1. Leave Navisworks open after the failure if possible.
2. Double-click RUN-BIMLog-Failure-Collector.bat.
3. Send the generated BIMLog-Navisworks2025-Failure-YYYYMMDD-HHMMSS.zip from your Desktop to Roberto/Main 04.
4. Also send a screenshot of the visible Navisworks error if present.

Optional failed XML: drag the exact BIMLog-Viewpoints.xml onto RUN-BIMLog-Failure-Collector.bat.

The collector is read-only toward Navisworks, BIMLog, Windows configuration, and installed bundles. It collects diagnostics into a temporary folder, creates one ZIP on the Desktop, and removes only its own temporary folder. It does not collect credentials.
