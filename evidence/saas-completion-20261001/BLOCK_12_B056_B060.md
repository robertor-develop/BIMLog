# SaaS completion Block 12 — B056–B060

## B056 — Account and email verification

Adds expiring, single-use, SHA-256-token email verification with delivery status, resend replacement, explicit failure, and a public confirmation route. Tokens are never stored in plaintext.

## B057 — Company creation and join continuity

Shows the authenticated company as the onboarding tenant boundary and preserves the existing secure invitation-only join authority. Workflows never join a company by name.

## B058 — Work-profile selection

Captures a bounded personal work profile for guidance without modifying project roles, authorization, or commercial entitlement.

## B059 — First-project wizard

Creates the canonical project and membership through the existing project API. Existing members can continue without duplicate creation. New projects hand off to `/projects/:id/intake`; assignment may remain pending.

## B060 — Intelligent defaults and release acceptance

Stores bounded frequent disciplines and deliverables, keeps Shop Drawings first by default, and completes only after verified email, profile, and project membership exist. The setup is resumable in PostgreSQL. Lens Next update discovery resolves a year-specific manifest so 2021 and 2025 never receive each other's package.

Focused acceptance: `pnpm run test:saas-block12`, API TypeScript, frontend TypeScript, and the prior public/onboarding suite pass. Full exact-head gate, push, dual-year package publication, Replit publication, exact live identity, authenticated Chrome smoke, and real installed Navisworks field acceptance are release-boundary gates.
