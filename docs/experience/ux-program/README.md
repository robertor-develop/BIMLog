## Design review and wrong turns

- Original Convention Builder can strand the user; the setup guide provides a direct same-project Intake return and warns to save before leaving. The underlying editor-return repair remains B04.
- Current APU defaults can conflict with the selected customer rate. Guide instructs retention/reporting, not repricing. UX111–120 owns the actual correction.
- Current named staffing activation gate is incompatible with future unstaffed floors. UX121–125 owns removal; B01 does not claim it is fixed.
- Missing canonical Contract versions remain a valid EDT guard; UX136–140 must connect one Contract source rather than bypassing it.
- Role labels help users choose a goal; they confer no access. Missing project context uses a visible recovery, never a guessed project.
- Detailed help and PDF remain available. Existing long manual content is not represented as fully repaired by this first block.
